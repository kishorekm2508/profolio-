Kishore — Two-page GitHub Pages Portfolio
A responsive, modern dark portfolio built with plain HTML, CSS, and JavaScript.

Files
index.html — Home and About page
projects.html — Projects and learning journey page
css/style.css — Shared responsive styling
js/main.js — Mobile menu and current year
Before publishing
Replace your-email@example.com with your email address in both HTML files.
Replace the generic GitHub and LinkedIn links with your profile URLs.
Update project descriptions and repository links so they reflect your real work.
Add or remove skills based on what you have learned.
Publish with GitHub Pages
Create a GitHub repository named your-username.github.io (or use any repository).
Upload all files and folders, keeping the same folder structure.
Open the repository's Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root) folder, then save.
Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.
For a project repository with a different name, the website address is usually:
https://your-username.github.io/repository-name/
